# Student Grade Calculator (Node.js)

A simple **command-line grade calculator** built with **Node.js**.  
The program allows you to input student scores, validates them, and then calculates:

- ✅ Total score  
- ✅ Average score  
- ✅ Final grade (A–F with + variations)  

It also uses **try...catch** blocks to handle invalid inputs gracefully.

---

## 🚀 Features
- Interactive input using [prompt-sync](https://www.npmjs.com/package/prompt-sync)  
- Validation for each score (must be a number between 0 and 100)  
- Automatic grade assignment based on average score  
- Error handling for invalid inputs
